THE PROJECT / OPEN SOURCE

ENGINEERED FOR EXPLORATION.

Linux Time Machine combines authentic historical x86 guest configurations for selected early eras with interactive educational reconstructions of later Linux history. The v86 browser emulator is configured for a compatibility-patched Linux 0.01 kernel (1991), Linux 0.99.12 with Slackware 1.01 (1993), Red Hat 5.2 (1998) and an Ubuntu-era 2004 recreation. Genuine kernel boot depends on the guest disk images and emulator binaries published with the deployed site; the educational terminal and later desktop reconstructions are not original operating systems.
