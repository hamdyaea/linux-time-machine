LINUX 0.01 · SEPTEMBER 1991

Linus Torvalds’ first Linux release was just 10,239 lines of source code (8,670 excluding comments and blank lines). It was written specifically for Intel 386 PCs, with 66 system-call entries, a MINIX filesystem, and no networking sockets.

Its tiny kernel already implemented processes, fork(), execve(), scheduling and a command-line environment. The scheduler selected runnable tasks by their remaining time counter; an early kernel panic simply printed a message and stopped.

LINUX 0.99.12 · AUGUST 1993

By 1993, Linux had evolved far beyond its first 1991 release. Slackware 1.01 bundled a practical Unix-like environment with shells, utilities, package installation and an early Linux distribution experience.

This machine boots a real Linux 0.99.12 kernel rebuilt for a modern toolchain, alongside a period Slackware disk image. The kernel and filesystem execute inside the browser’s x86 emulator—not in a simulated JavaScript shell.

    From a personal kernel experiment to the operating system behind modern infrastructure. Explore the milestones, then select a year in the cockpit to inspect its environment.

    1991 / ORIGINS

    A kernel is born

    Linus Torvalds publishes Linux 0.01 source code for Intel 80386 machines. The earliest release is a kernel, not a complete desktop operating system.

    HISTORICAL KERNEL ARCHIVE ↗
    1993 / DISTRIBUTIONS

    Linux becomes installable

    Slackware launches and Debian is announced. Distributions assemble the kernel, user-space tools, packaging and installation into a usable system.

    ABOUT DEBIAN ↗
    1998 / DESKTOPS

    The graphical revolution

    KDE 1.0 brings an integrated graphical desktop to Unix-like systems, while the wider Linux desktop ecosystem continues to grow.

    KDE ANNOUNCEMENTS ↗
    2004 / ACCESSIBILITY

    Ubuntu arrives

    Ubuntu 4.10, Warty Warthog, arrives in October 2004. The Linux 2.6 era expands hardware support and brings a more accessible desktop experience.
